BóbrRent - Car Rental Management System
BóbrRent is a comprehensive car rental solution featuring a multi-threaded Java server, a modern JavaFX desktop client, and an Oracle XE database backend.

====> Key Features
User Authentication: Secure login and signup with session persistence using UserSession.

Dynamic Catalog: A live car browsing interface with real-time status updates.

Intelligent Booking: Date-based rental logic with automated price calculation.

Transactional Integrity: SQL-based atomic transactions ensuring data consistency during bookings.

Personal Dashboard: View rental history and profile details instantly.

----- System Architecture
The project is built on a Three-Tier Architecture:

Frontend: JavaFX (FXML) for a responsive desktop UI.

Middleware: Multi-threaded Java Socket Server managing concurrent requests on port 1234.

Backend: Oracle SQL XE for robust relational data persistence.

----- Database Schema
The database uses three core tables with relational constraints.

SQL

CREATE TABLE RENTALS (
    RENTAL_ID NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    CUSTOMER_PHONE VARCHAR2(20),
    BRAND VARCHAR2(50),
    MODEL VARCHAR2(50), 
    START_DATE DATE,
    END_DATE DATE,
    TOTAL_PRICE NUMBER(10, 2),
    CONSTRAINT fk_rent_cust FOREIGN KEY (CUSTOMER_PHONE) REFERENCES CUSTOMERS(PHONE)
);
----- Installation & Setup
Database: Ensure Oracle XE is running and execute the provided SQL scripts to create CUSTOMERS, CAR_INFO, and RENTALS tables.

Server: Update the database credentials in BobrServer.java and run the main method.

Client: Launch the JavaFX Main class. Ensure bookings.fxml is correctly placed in the resources folder to avoid Location is not set errors.

----- Technical Reliability (Grade 5 Standards)
Persistence: Implements permanent storage via JDBC with explicit transaction management (conn.commit()).

Error Handling: Robustly handles common database errors like ORA-00904 by validating SQL identifiers.

Unit Logic: Uses ChronoUnit for precise date calculations and logic validation within controllers.
